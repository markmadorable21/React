Proper React Set-up

1. npx create-vite@6.5.0 - install the package with version after @ and can run create-vite in the command line

2. npx create-vite is equal to "npm create vite"

3. Define project name, choose framework, and then variant 

4. cd project-name

5. npm install

6. npm run dev

7. files explanation

  7.1 npm_modules = a folder where npm installs all packages

  7.2 src = folder contains code of our website (CSS, JavaSctipt, HTML)

  7.3  assets =  contains images we display in website

  7.4  public = files that should be available in the public
    7.4.1 = we can access it using URL

  7.5  eslint.config.js = highlights problems in JavaScript code

    7.5.1 eslint uses this file

    7.5.2 to install eslint, use Extension tab
    
  7.6 index.html = contains the html elements same with file chatbot.html

    7.6.1 main difference is that it loads to a different file

  7.7 package-lock.json =  saves version numbers for all the packages, automatically updated by npm

  7.8 package.json = contains list of packages and other info about our packages, automatically updated by npm so no need to update 

  7.9 vite.config.js = configures vite

    7.9.1 Vite = tool that we used to set up this project

      7.9.1.1 Vite also helps us build the website, takes all JS and HTML codes

      7.9.1.2 Vite also creates a server (a server puts our website at a URL localhost:5173)

      7.9.1.3 Vite also auto refresh the server when we change anything in the website, same with Live Server (or it simply replaces the extension)

  7.10 css files:
    7.10.1 index.css = for whole website
    7.10.2 App.css = for components inside the website
